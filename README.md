# 팩맨 🟡

유령을 피해 미로의 점을 모두 먹고, 파워 쿠키로 역습하는 고전 게임입니다. 서버 없이 `index.html` 만 열면 돌아갑니다.

## 조작
- 키보드: 방향키 또는 `WASD` 로 방향 바꾸기(팩맨은 혼자 계속 움직임).
- 폰: 아래 패드를 누르거나 화면을 밀기.

## 규칙
- 점을 모두 먹으면 클리어, 유령에 닿으면 목숨이 줄어듭니다.
- 큰 알(파워 쿠키)을 먹으면 잠깐 유령이 파랗게 변해 먹을 수 있습니다. 최고 점수는 `pacmanBest`.

## 구조
- `game.js` 화면·입력·소리, `logic.js` 규칙(미로·유령 움직임·점수).
- 규칙은 DOM 없는 `logic.js`, 시험은 `node --test` (`test/logic.test.js`).
